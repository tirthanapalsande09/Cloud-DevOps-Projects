
# AWS S3 Static Website Hosting

## 1. Project Overview
This project demonstrates how to host a static website using Amazon Simple Storage Service (Amazon S3).

The website files, including HTML and CSS, are uploaded to an S3 bucket and made accessible through the S3 static website hosting feature.

## 2. Objectives
- Understand Amazon S3 and its features.
- Create and configure an S3 bucket.
- Enable static website hosting.
- Configure bucket permissions for public access.
- Upload HTML and CSS website files.
- Access the hosted website through its endpoint.

## 3. AWS Services and Technologies
- Amazon S3
- HTML
- CSS
- AWS Management Console

## 4. Architecture

User Browser → S3 Static Website Endpoint → S3 Bucket → HTML and CSS Files

## 5. Implementation Steps

1. Logged in to the AWS Management Console.
2. Opened the Amazon S3 service.
3. Created an S3 bucket with a unique bucket name.
4. Uploaded the website files (index.html and style.css).
5. Enabled static website hosting in the bucket properties.
6. Configured the required bucket permissions for public access.
7. Set the index document to `index.html`.
8. Accessed the website using the S3 website endpoint.

## 6. Expected Outcome

A static website hosted on Amazon S3 that can be accessed through its website endpoint.

## 7. Key Learnings

- Amazon S3 bucket creation and configuration.
- Static website hosting.
- Bucket policies and public access permissions.
- Uploading and managing website files.
- Basic AWS cloud deployment.
