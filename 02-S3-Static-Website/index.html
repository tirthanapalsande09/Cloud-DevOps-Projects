About This Project

This project demonstrates how to host a static website using Amazon S3. HTML and CSS files are uploaded to an S3 bucket, and static website hosting is configured to make the website accessible through its endpoint.

Technologies Used

Amazon S3

Cloud storage and static website hosting.

HTML

Structure and content of the website.

CSS

Website styling and responsive layout.
